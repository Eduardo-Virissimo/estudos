# 📚 Módulo 01: Fundamentos e 5 Vs do Big Data

> **Foco do módulo:** entender o que é Big Data, por que ele surgiu e como dados brutos se transformam em informação útil.

## 🧩 1) Dados, informação e conhecimento

- **Dado** é um registro bruto, sem interpretação suficiente para orientar uma decisão por si só.
- **Informação** é o dado tratado, contextualizado e relacionado a um objetivo.
- **Conhecimento** surge quando a informação é interpretada e usada para orientar ação.

Exemplo:

- dado: `1200`
- informação: `1200 pedidos foram feitos ontem`
- conhecimento: `a campanha aumentou a demanda e será preciso reforçar estoque`

## 🔄 2) Como os dados viram informação

De forma clássica, Davenport e Prusak destacam cinco operações importantes:

1. **Contextualização**: entender para que o dado será usado.
2. **Categorização**: classificar o dado em grupos úteis.
3. **Cálculo**: aplicar tratamento estatístico ou matemático.
4. **Correção**: remover erros, duplicidades e inconsistências.
5. **Condensação**: resumir o que é relevante para facilitar a decisão.

Essas etapas ajudam a separar simples armazenamento de geração real de valor.

## 🌐 3) O que é Big Data

Big Data não significa apenas "muito dado". O termo é usado quando o volume, a velocidade, a variedade ou a complexidade dos dados ultrapassam o que ferramentas tradicionais tratam com eficiência.

Na prática, Big Data envolve:

- coleta de dados em grande escala;
- armazenamento distribuído;
- processamento em lote ou em fluxo;
- análise para gerar insight de negócio;
- tecnologia, processo e governança atuando juntos.

## 📖 4) Definições de referência

- **Doug Laney** popularizou a visão baseada em volume, velocidade e variedade.
- **TechAmerica Foundation** reforçou que Big Data exige novas formas de captura, armazenamento e análise.
- **Taurion** enfatiza que Big Data só faz sentido quando leva à geração de valor.
- **Pinto** destaca a combinação entre tecnologia, prazo de resposta e capacidade analítica.

Em síntese: **Big Data é a capacidade de transformar dados complexos e volumosos em decisões úteis no tempo adequado**.

## 🖐️ 5) Os 5 Vs do Big Data

| V | Significado prático |
| --- | --- |
| **Volume** | Grande quantidade de dados gerados, armazenados e processados. |
| **Velocidade** | Rapidez com que os dados chegam, mudam e precisam ser tratados. |
| **Variedade** | Diversidade de formatos, fontes e estruturas. |
| **Veracidade** | Confiabilidade, consistência e qualidade dos dados. |
| **Valor** | Capacidade de gerar benefício real para o negócio ou para a operação. |

Os 5 Vs são uma referência útil, mas o peso de cada um varia conforme o contexto do projeto.

## 🎯 6) Ideia central do módulo

Big Data só tem sentido quando três elementos aparecem juntos:

- desafio técnico real;
- tratamento adequado dos dados;
- uso orientado a decisão.

Sem isso, existe apenas acúmulo de dados, não inteligência.
