## Ordem sugerida

1. Entender valores, variaveis e tipos
2. Dominar operadores, comparacoes e condicionais
3. Praticar lacos, funcoes, arrays e objetos
4. Aprender DOM e eventos para mexer na pagina
5. Fechar com JSON, storage e assincronismo

## Resultado esperado

Ao terminar essa trilha, voce deve conseguir:

- ler e escrever codigo JavaScript basico com seguranca
- manipular dados com arrays e objetos
- criar funcoes reutilizaveis
- alterar elementos da pagina com DOM
- consumir dados assincronos sem se perder no fluxo
