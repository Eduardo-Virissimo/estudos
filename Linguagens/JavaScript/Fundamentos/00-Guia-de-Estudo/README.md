# Guia de Estudo de JavaScript

## O que e fundamental em JavaScript

Se voce quer uma base forte, estes blocos sao obrigatorios:

- sintaxe basica e declaracao de variaveis
- tipos primitivos e valores especiais
- operadores e comparacoes
- condicionais e repeticao
- funcoes
- arrays e objetos
- manipulacao de strings e numeros
- DOM e eventos
- JSON, storage e assincronismo

## Como estudar

Use este ciclo em cada topico:

1. Ler a explicacao e executar os exemplos
2. Reescrever os exemplos com suas palavras
3. Criar 3 variacoes pequenas do mesmo codigo
4. Explicar em voz alta o que aconteceu
5. Resolver um exercicio sem olhar

## Regras praticas para nao se perder

- prefira `const` por padrao
- use `let` quando o valor mudar
- evite `var` em codigo novo
- pratique com `console.log()` para enxergar o fluxo
- compare com `===` e `!==` quase sempre
- quebre problemas grandes em funcoes pequenas

## Ferramentas minimas

- navegador com DevTools
- Node.js para rodar arquivos `.js`
- editor de codigo

## Exemplo de rotina curta

```js
const nome = "Edu";
let tentativas = 0;

tentativas += 1;

if (tentativas > 0) {
  console.log(`Estudando JS, ${nome}!`);
}
```

## Perguntas que voce precisa saber responder

- qual a diferenca entre `const` e `let`?
- o que e `undefined`?
- quando usar `if`, `for` e `while`?
- qual a diferenca entre funcao e metodo?
- quando usar array e quando usar objeto?
- o que e uma Promise?
