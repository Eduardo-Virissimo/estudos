# 📚 Módulo 06: Linguagem R para Análise de Dados

> **Foco do módulo:** entender o diferencial do R em estatística e visualização avançada.

## 📈 1) Por que R é relevante

- Linguagem orientada à estatística.
- Muito forte em pesquisa e ambiente acadêmico.
- Ecossistema robusto para modelagem, testes e gráficos.

## 📦 2) Bibliotecas essenciais (resumo)

- **dplyr:** manipulação de dados eficiente.
- **tidyr:** organização e limpeza de dados.
- **ggplot2:** visualização avançada e altamente customizável.
- **data.table:** alta performance com grandes bases.
- **caret:** pipeline para treino e avaliação de modelos.
- **randomForest:** classificação e regressão com florestas aleatórias.
- **lme4:** modelos lineares e de efeitos mistos.
- **forecast:** modelagem e previsão de séries temporais.

## 🧠 3) Quando R costuma ser melhor escolha

- Quando há alta exigência estatística.
- Quando o foco é análise inferencial detalhada.
- Quando o time já trabalha com fluxo acadêmico-científico.

## 🎯 4) O que memorizar para prova

- R foi projetado para análise estatística.
- ggplot2 e dplyr são pilares do ecossistema.
- R e Python podem ser complementares no mesmo projeto.
