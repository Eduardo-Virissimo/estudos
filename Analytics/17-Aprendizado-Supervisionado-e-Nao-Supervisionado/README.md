# 📚 Módulo 17: Aprendizado Supervisionado e Não Supervisionado

> **Foco do módulo:** diferenciar as duas abordagens mais cobradas e entender seu fluxo de aplicação.

## 🧑‍🏫 1) Aprendizado supervisionado

No aprendizado supervisionado, o modelo aprende com **dados rotulados**.

Isso significa que já existe uma resposta conhecida para cada exemplo de treino.

### Para que ele serve

- classificação;
- regressão;
- reconhecimento de padrões;
- previsão com base em histórico.

### Etapas principais

1. coletar e preparar dados com entradas e saídas corretas;
2. escolher o algoritmo;
3. treinar o modelo;
4. avaliar em dados de teste;
5. ajustar e otimizar.

### Exemplos comuns

- classificar e-mails em spam/não spam;
- prever vendas;
- classificar imagens;
- estimar risco ou probabilidade.

## 🕵️ 2) Aprendizado não supervisionado

No aprendizado não supervisionado, o modelo trabalha com **dados sem rótulos**.

O objetivo passa a ser encontrar estruturas ocultas nos dados.

### Para que ele serve

- clusterização;
- redução de dimensionalidade;
- detecção de anomalias;
- descoberta de padrões em dados complexos.

### Etapas principais

1. coletar e preparar os dados;
2. escolher o algoritmo;
3. extrair padrões ou agrupamentos;
4. interpretar os resultados;
5. aplicar os insights no problema;
6. validar e ajustar parâmetros.

### Exemplos comuns

- segmentação de clientes;
- análise de mercado;
- identificação de fraudes;
- agrupamento de documentos ou textos.

## ⚖️ 3) Diferença central

| Aspecto            | Supervisionado                      | Não supervisionado                         |
| ------------------ | ----------------------------------- | ------------------------------------------ |
| Dados              | possuem rótulos                     | não possuem rótulos                        |
| Meta               | prever ou classificar               | descobrir padrões                          |
| Saída esperada     | resposta conhecida ou estimada      | grupos, estruturas, relações               |
| Exemplo clássico   | spam/não spam                       | segmentação de clientes                    |
| Validação          | mais objetiva, com resposta correta | mais interpretativa e dependente do caso   |

## 🧠 4) Critério rápido de escolha

- Se já existe uma variável-resposta conhecida, pense em **supervisionado**.
- Se você quer explorar os dados e descobrir estrutura sem resposta pronta, pense em **não supervisionado**.

## 📌 5) Observação importante

No aprendizado não supervisionado, a validação tende a ser menos direta, porque não existe um rótulo final para comparar com a resposta do modelo.
