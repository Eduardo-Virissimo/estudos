# 📚 Módulo 05: Python para Análise de Dados

> **Foco do módulo:** revisar por que Python é tão usado em Analytics e quais bibliotecas mais caem.

## 🐍 1) Por que Python é forte em Analytics

- Sintaxe simples e legível.
- Grande ecossistema de bibliotecas.
- Uso amplo em análise, automação, machine learning e integração com BI.

## 📦 2) Bibliotecas essenciais (resumo)

- **Pandas:** manipulação de dados tabulares (DataFrames).
- **NumPy:** operações numéricas de alto desempenho.
- **Matplotlib / Seaborn:** visualização de dados.
- **Scikit-learn:** algoritmos clássicos de machine learning.
- **TensorFlow / PyTorch:** deep learning e redes neurais.
- **SciPy / Statsmodels:** métodos matemáticos e estatísticos.

## 🧩 3) Uso no fluxo analítico

- Coleta e preparação de dados.
- Exploração e visualização.
- Treinamento de modelos.
- Geração de relatórios e integração com ferramentas como Power BI.

## 🎯 4) O que memorizar para prova

- Python é linguagem geral e versátil.
- Pandas, NumPy e Scikit-learn formam o núcleo de análise + modelagem.
- Matplotlib/Seaborn são base de visualização em código.
