# 📚 Módulo 14: Representação Gráfica de Dados

> **Foco do módulo:** entender por que a visualização é parte central de Analytics e saber escolher os gráficos mais usados.

## 📊 1) O papel da representação gráfica

A representação gráfica dos dados serve para:

- resumir informações complexas de forma visual;
- comparar categorias, valores e séries temporais;
- identificar padrões, tendências e anomalias;
- comunicar resultados com clareza para públicos diferentes.

Em Analytics, visualizar bem os dados ajuda tanto na exploração inicial quanto na apresentação final dos insights.

## 🧩 2) Tipos de gráfico mais importantes

| Gráfico                | Quando usar                                        | O que ele destaca                           |
| ---------------------- | -------------------------------------------------- | ------------------------------------------- |
| Barras                 | comparar categorias                                | diferenças de magnitude entre grupos        |
| Linhas                 | acompanhar valores ao longo do tempo               | tendência, crescimento, queda, sazonalidade |
| Dispersão              | analisar duas variáveis numéricas                  | relação, correlação e possíveis outliers    |
| Pizza                  | mostrar composição percentual de um todo           | participação relativa de cada parte         |
| Área                   | acompanhar evolução com noção de acúmulo/proporção | crescimento acumulado ao longo do tempo     |

## 📈 3) Leitura prática dos gráficos

- **Gráfico de barras:** ideal para comparar quantidades entre categorias.
- **Gráfico de linhas:** ideal para séries temporais e leitura de tendência.
- **Gráfico de dispersão:** útil para ver se duas variáveis se movem juntas ou em sentidos opostos.
- **Gráfico de pizza:** útil quando a meta é mostrar divisão percentual do total.
- **Gráfico de área:** útil para mostrar evolução temporal com ênfase no volume acumulado.

## 🔍 4) O que a visualização ajuda a perceber

- padrões de crescimento ou queda;
- comportamentos sazonais;
- relações entre variáveis;
- valores discrepantes;
- diferenças entre grupos.

## ⚠️ 5) Erro comum

Escolher o gráfico sem considerar:

- o tipo de dado;
- o objetivo da análise;
- a comparação que precisa ser feita.

Gráfico bonito não substitui gráfico adequado.
