# 📚 Módulo 08: Estatística para Análise de Dados

> **Foco do módulo:** entender por que estatística é base da análise de dados em negócios, pesquisa e tomada de decisão.

## 🧠 1) Papel da estatística em Analytics

Estatística permite:

- coletar e organizar dados;
- resumir padrões relevantes;
- tirar conclusões com base em evidências;
- tomar decisões com menor incerteza.

## 🔍 2) Dois blocos principais

| Bloco                   | Pergunta que responde                     | Técnicas típicas                                      |
| ----------------------- | ----------------------------------------- | ----------------------------------------------------- |
| Estatística Descritiva  | Como os dados se comportam?               | média, mediana, moda, desvio padrão, gráficos         |
| Estatística Inferencial | O que podemos concluir sobre a população? | teste de hipóteses, intervalo de confiança, regressão |

## 🔗 3) Conexão com as abordagens de Analytics

- **Descritiva:** usa estatística descritiva para resumir o passado e o presente.
- **Preditiva e Prescritiva:** usam inferência para estimar cenários e apoiar decisões.

## 🎯 4) Mensagem para prova

Sem estatística, análise vira opinião. Com estatística, análise vira argumento técnico verificável.
