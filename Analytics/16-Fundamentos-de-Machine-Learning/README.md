# 📚 Módulo 16: Fundamentos de Machine Learning

> **Foco do módulo:** entender o que é machine learning, qual é seu objetivo e onde ele aparece em Analytics.

## 🤖 1) O que é machine learning

Machine learning é um subcampo da inteligência artificial voltado ao desenvolvimento de algoritmos que aprendem a partir de dados.

Em vez de programar todas as regras manualmente, treinamos modelos para:

- reconhecer padrões;
- fazer previsões;
- apoiar decisões em novos dados.

## 🎯 2) Objetivo central

O objetivo do machine learning é permitir que sistemas melhorem seu desempenho em tarefas específicas com base na experiência obtida nos dados.

Em termos práticos:

- entra dado histórico;
- o modelo aprende relações e padrões;
- depois faz previsão ou classificação em casos novos.

## 🌍 3) Aplicações mais comuns

Exemplos frequentes:

- publicidade personalizada;
- filtros de spam;
- sistemas de recomendação;
- reconhecimento facial;
- medicina;
- finanças;
- assistentes virtuais.

## 🧭 4) As 3 grandes formas de aprendizado

- **Supervisionado:** aprende com dados rotulados.
- **Não supervisionado:** procura padrões sem rótulos.
- **Por reforço:** aprende por tentativa, erro e recompensa.

Essas três formas organizam quase toda a introdução ao tema.

## ⚙️ 5) Fluxo geral de um projeto de ML

Mesmo variando conforme o problema, a lógica costuma seguir:

1. definir o problema;
2. reunir e preparar dados;
3. escolher algoritmo;
4. treinar o modelo;
5. avaliar desempenho;
6. ajustar e melhorar.

## 🧩 6) Ligação com Analytics

Machine learning amplia o Analytics quando queremos ir além da descrição do passado e começar a:

- prever comportamento;
- segmentar padrões;
- automatizar classificações;
- otimizar decisões.
