# 📚 Módulo 03: Abordagens de Analytics

> **Foco do módulo:** comparar análise descritiva, preditiva e prescritiva e saber quando usar cada uma.

## 🧭 1) Visão geral

- **Descritiva:** explica o que aconteceu.
- **Preditiva:** estima o que pode acontecer.
- **Prescritiva:** recomenda o que deve ser feito.

## 📊 2) Comparação rápida

| Tipo        | Pergunta-chave       | Base principal            | Resultado            |
| ----------- | -------------------- | ------------------------- | -------------------- |
| Descritiva  | O que aconteceu?     | Dados históricos e atuais | Resumo e padrão      |
| Preditiva   | O que vai acontecer? | Histórico + modelos       | Previsões            |
| Prescritiva | O que fazer agora?   | Previsões + otimização    | Recomendação de ação |

## 🛠️ 3) Técnicas comuns

- **Descritiva:** medidas estatísticas, tabelas, dashboards.
- **Preditiva:** regressão, classificação, séries temporais, mineração de dados.
- **Prescritiva:** simulação, otimização e regras de decisão.

## 🧪 4) Exemplos clássicos

- **Descritiva:** produto mais vendido por região.
- **Preditiva:** probabilidade de inadimplência de clientes.
- **Prescritiva:** melhor estratégia para aumentar vendas com restrição de orçamento.

## 🔗 5) Ponto de prova importante

As três abordagens **não são excludentes**. Em projetos reais, costumam ser combinadas na mesma solução analítica.
