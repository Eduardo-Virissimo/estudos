# 📚 Módulo 18: Aprendizado por Reforço e Deep Learning

> **Foco do módulo:** fechar os tipos de aprendizado com reforço e entender onde deep learning entra dentro de machine learning.

## 🎮 1) O que é aprendizado por reforço

Aprendizado por reforço é a abordagem em que um **agente** aprende a tomar ações em um **ambiente** para maximizar uma **recompensa** ao longo do tempo.

### Componentes principais

- **Agente:** quem toma a decisão.
- **Ambiente:** onde a decisão acontece.
- **Recompensa:** sinal que indica se a ação foi boa ou ruim.

### Ideia central

O agente aprende por tentativa e erro, ajustando sua política de ação para acumular o maior retorno possível.

## 🧭 2) Etapas gerais do reforço

1. definir o problema;
2. escolher ou criar o ambiente;
3. definir estados e ações;
4. modelar a função de recompensa;
5. escolher o algoritmo de RL;
6. treinar o agente;
7. ajustar hiperparâmetros;
8. avaliar e melhorar.

### Aplicações citadas

- jogos;
- robótica;
- automação;
- finanças;
- medicina;
- controle autônomo.

## 🧠 3) O que é deep learning

Deep learning é uma abordagem avançada de machine learning baseada em **redes neurais profundas**.

Ela se destaca por:

- trabalhar bem com dados não estruturados;
- extrair padrões hierárquicos;
- lidar com tarefas complexas de visão, texto e áudio.

## 🕸️ 4) Arquitetura básica do deep learning

Em redes profundas:

- a camada de entrada recebe os dados;
- camadas intermediárias aprendem representações cada vez mais complexas;
- a camada de saída produz a previsão final.

O treinamento ocorre por meio de **backpropagation**, que ajusta pesos e vieses para reduzir o erro.

## ⚙️ 5) Fluxo geral de um projeto de deep learning

1. definir o problema;
2. coletar e preparar dados;
3. separar treino, validação e teste;
4. escolher a arquitetura da rede;
5. construir o modelo;
6. configurar hiperparâmetros;
7. treinar;
8. avaliar;
9. ajustar;
10. implantar e monitorar, se necessário.

## 📌 6) Quando pensar em cada abordagem

- **Reforço:** quando há decisão sequencial e recompensa.
- **Deep learning:** quando o problema exige modelagem complexa, especialmente com imagem, texto, som ou grande volume de dados.

## 🔗 7) Relação entre os temas

- Aprendizado por reforço é um **tipo de aprendizado**.
- Deep learning é uma **família/modelagem dentro de machine learning**.
- Os dois podem até se combinar, como em **deep reinforcement learning**.
