# 📚 Módulo 07: Python x R e Revisão de Fundamentos

> **Foco do módulo:** fechar os fundamentos comparando Python e R e consolidar revisão objetiva.

## ⚖️ 1) Python x R (comparação direta)

| Critério      | Python                           | R                               |
| ------------- | -------------------------------- | ------------------------------- |
| Propósito     | Linguagem de uso geral           | Linguagem focada em estatística |
| Sintaxe       | Simples e legível                | Voltada à análise de dados      |
| Versatilidade | Alta (web, dados, IA, automação) | Forte em estatística e pesquisa |
| Dados         | Pandas/NumPy                     | dplyr/data.table                |
| Visualização  | Matplotlib/Seaborn               | ggplot2                         |

## 🤝 2) Ideia-chave

Não é disputa absoluta: em muitos projetos, Python e R são **complementares**.

- Python: pré-processamento, produção e integração.
- R: análises estatísticas profundas e visualizações analíticas.

## 🧪 3) Perguntas de treino para revisar

1. Qual diferença entre análise preditiva e prescritiva?
2. Por que o ciclo de Analytics é iterativo?
3. Em qual cenário você escolheria R em vez de Python?
4. Como transformar insight em ação mensurável?
5. Qual é o papel do profissional de Analytics diante de riscos éticos e de privacidade?

## 📝 4) Roteiro de revisão de 15 minutos

- **5 min:** conceitos-base (módulos 01 e 03).
- **5 min:** processo em 10 etapas (módulo 02).
- **5 min:** ferramentas + Python x R (módulos 04 a 07).

## 📌 5) Fechamento para prova

- Analytics é um processo **contínuo e iterativo**: analisar, agir, medir e melhorar.
- O valor não está no dado em si, mas na **decisão melhorada**.
- A escolha de método e ferramenta depende do objetivo, do contexto e da qualidade dos dados.
