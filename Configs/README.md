# Minhas configurações do Obsidian

Esta pasta reúne uma cópia das configurações e dos snippets usados neste vault.

## Extensões utilizadas

A lista está em [Extensões.md](./Extensões.md). As extensões instaladas e ativas continuam sendo gerenciadas pelo Obsidian em `.obsidian/plugins`.

## CSS snippets

- [cursor-smooth.css](./cursor-smooth.css)
- [custom-rainbow-colors.css](./custom-rainbow-colors.css)

Os snippets estão ativos no Obsidian. As cópias originais ficam em `.obsidian/snippets`.

## Arquivos de configuração

- [community-plugins.json](./community-plugins.json): extensões da comunidade ativas.
- [appearance.json](./appearance.json): tema e snippets CSS ativos.
