# 📚 Módulo 18: Técnicas de IA Aplicadas ao Monitoramento

> **Foco do módulo:** organizar as principais técnicas usadas em monitoramento e quando cada uma entra.

## 🤖 1) Machine Learning

No monitoramento, machine learning pode ser usado para:

- classificar eventos;
- prever falhas;
- detectar anomalias;
- otimizar decisões em tempo real.

### Formas comuns

- supervisionado;
- não supervisionado;
- por reforço;
- deep learning com CNNs e RNNs.

## 🚨 2) Detecção de anomalias

É uma técnica voltada a identificar comportamentos fora do padrão.

É muito importante em:

- segurança cibernética;
- manutenção preditiva;
- fraudes;
- monitoramento de saúde.

## 💬 3) Processamento de Linguagem Natural

O PLN entra quando os dados de monitoramento são textuais, como:

- logs;
- mensagens de erro;
- comentários;
- tickets;
- texto de atendimento.

Aplicações comuns:

- análise de sentimentos;
- extração de informação;
- classificação de texto;
- reconhecimento de entidades.

## 👁️ 4) Visão computacional

Usada quando o monitoramento depende de:

- imagens;
- vídeos;
- objetos;
- pessoas;
- veículos;
- eventos visuais.

Exemplos comuns incluem `YOLO`, `SSD`, `ResNet` e `Inception`.

## 🌊 5) Processamento de streams

É a análise de dados à medida que eles chegam.

Ferramentas comuns:

- `Apache Kafka`
- `Apache Flink`
- `Apache Storm`

Isso é central em cenários de tempo real.

## 🧩 6) Reconhecimento de padrões

Ajuda a encontrar estruturas relevantes em dados complexos.

Exemplos comuns:

- `Apriori`
- `K-Means`
- Árvores de Decisão
- `PCA`

## 🧭 7) Como escolher a técnica

A escolha depende de:

- natureza dos dados;
- objetivo do monitoramento;
- necessidade de tempo real;
- escalabilidade;
- recursos disponíveis.

Em muitos casos, a melhor solução é híbrida.
