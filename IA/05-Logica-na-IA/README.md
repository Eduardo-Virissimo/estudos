# 📚 Módulo 05: Lógica na IA

> **Foco do módulo:** entender como a lógica representa fatos e sustenta inferência em sistemas inteligentes.

## 🧠 1) Papel da lógica na IA

A lógica representa conhecimento por meio de:

- símbolos;
- regras;
- operações dedutivas.

Ela é valiosa porque permite expressar fatos com precisão e verificar consistência.

## 🔍 2) Onde a lógica aparece

A lógica é usada em áreas como:

- raciocínio automático;
- planejamento;
- programação em lógica;
- sistemas especialistas.

## 🧩 3) Tipos principais de lógica

| Tipo                    | Ideia central                                  | Uso típico                                   |
| ----------------------- | ---------------------------------------------- | -------------------------------------------- |
| Proposicional           | trabalha com proposições verdadeiras ou falsas | regras simples e automação                   |
| De predicados           | representa relações entre objetos              | conhecimento mais rico e inferência          |
| Modal                   | trabalha com necessidade e possibilidade       | tempo, crenças, multiagentes                 |
| Fuzzy                   | usa graus de verdade                           | incerteza, controle contínuo, linguagem vaga |

## 🧪 4) Leitura prática de cada uma

- **Lógica proposicional:** boa para regras simples do tipo “se... então...”.
- **Lógica de predicados:** melhor quando precisamos representar objetos e relações.
- **Lógica modal:** útil quando o problema envolve possibilidade, necessidade ou estados.
- **Lógica fuzzy:** útil quando verdadeiro/falso é insuficiente.

## ⚖️ 5) Critério de escolha

A lógica escolhida depende de:

- complexidade do problema;
- tipo de conhecimento;
- necessidade de lidar com incerteza;
- tipo de inferência desejada.

## 📌 6) Ideia central do módulo

Quanto mais complexo e incerto o domínio, maior a necessidade de uma lógica mais expressiva do que a lógica binária simples.
