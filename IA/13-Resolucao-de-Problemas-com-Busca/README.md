# 📚 Módulo 13: Resolução de Problemas com Busca

> **Foco do módulo:** entender por que muitos problemas de IA são tratados como busca em um espaço de estados.

## 🧩 1) O que é resolução de problemas em IA

Em IA, resolver problemas significa encontrar uma solução para uma situação complexa dentro de um conjunto de possibilidades.

Em muitos casos, isso é modelado como:

- um **estado inicial**;
- um **estado objetivo**;
- um conjunto de **transições** entre estados.

## 🗺️ 2) Espaço de estados

O espaço de estados é o conjunto de configurações possíveis do problema.

Podemos pensar nele como um grafo em que:

- cada nó é um estado;
- cada ligação representa uma transição possível.

A busca tenta encontrar um caminho do estado inicial até o estado objetivo.

## 🎯 3) Onde isso aparece

A resolução de problemas com busca é importante em:

- jogos;
- robótica;
- planejamento automatizado;
- diagnóstico médico;
- processamento de linguagem natural.

## ⚠️ 4) Desafios centrais

Os principais desafios são:

- complexidade do espaço de estados;
- limitação de memória e processamento;
- necessidade de boas heurísticas;
- equilíbrio entre eficiência e otimalidade.

## 🧭 5) Duas grandes famílias de busca

- **Busca não informada:** procura sem conhecimento extra sobre a posição da solução.
- **Busca informada:** usa heurísticas para explorar caminhos mais promissores.

## 📌 6) Ideia central do módulo

Em IA, muitos problemas difíceis deixam de ser “caos” quando são modelados como busca estruturada em um espaço de estados.
