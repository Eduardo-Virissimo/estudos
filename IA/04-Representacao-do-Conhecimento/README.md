# 📚 Módulo 04: Representação do Conhecimento

> **Foco do módulo:** entender como o conhecimento precisa ser organizado para que a máquina possa raciocinar.

## 🧩 1) O que é representação do conhecimento

Representação do conhecimento é a forma de capturar e organizar informações para que um sistema de IA possa:

- compreender fatos;
- relacionar conceitos;
- raciocinar;
- tomar decisões.

## 🧠 2) Por que ela é essencial

Sem representação adequada, a IA não consegue usar o conhecimento de modo inteligente.

Ela é a base para tarefas como:

- solução de problemas;
- inferência;
- comunicação;
- apoio à decisão.

## 📝 3) Um mesmo fato pode ser representado de várias formas

A mesma informação pode aparecer em:

- lógica;
- redes semânticas;
- ontologias.

Isso mostra que não existe uma única forma universal de representar conhecimento.

## 🏗️ 4) As 4 partes principais da representação

### Léxica

Define o vocabulário disponível para descrever o domínio.

### Estrutural

Define como os elementos podem ser combinados e organizados.

### Procedural

Define como acessar, consultar, modificar e inferir a partir do conhecimento.

### Semântica

Define o significado das descrições e relações.

## 🎯 5) O que uma boa representação precisa permitir

Ela deve permitir representar:

- objetos;
- atributos dos objetos;
- relações entre objetos.

## 📌 6) Ideia central do módulo

A escolha da representação afeta diretamente a capacidade da IA de entender o domínio, raciocinar e interagir com o mundo.
